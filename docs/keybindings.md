# MangoWM keybindings

These bindings are transcribed from the current configuration details shared during setup. Confirm them against the live `~/.config/mango/config.conf` before treating this page as a definitive reference.

| Binding | Action |
|---|---|
| `Super + R` | Reload MangoWM configuration |
| `Alt + Space` | Open the Rofi application launcher |
| `Alt + Enter` | Open Kitty |
| `Super + M` | Quit MangoWM |
| `Alt + Q` | Close the focused client |
| `Ctrl + 1–4` | View tag 1–4 |
| `Alt + 1–4` | Move the focused client to tag 1–4 |
| `Super + Left / Right` | View the adjacent tag |
| `Ctrl + Left / Right` | View the adjacent tag that has a client |
| `Ctrl + Super + Left / Right` | Move the focused client to the adjacent tag |

## Mouse

| Binding | Action |
|---|---|
| `Super + Left mouse button` drag | Move a floating window |
| `Super + Right mouse button` drag | Resize a floating window |
| Middle mouse button | Toggle maximize |

## Notes

- The desktop currently uses four Mango tags.
- A physical keyboard key previously identified as F9 reported itself to the session as `XF86AudioNext`. The wallpaper-picker shortcut is therefore intentionally omitted here until its actual working binding is confirmed.
- Floating-window behavior and any additional bindings should be checked against the active config before adding them to this document.
